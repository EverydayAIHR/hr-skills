How a CV gets to the employer's inbox

A Lovable app can't send mail from the browser. The Apply button saves the CV, then a small server function (a Lovable Cloud Edge Function) emails it to the address set on that job.

  1. Candidate submits the form. Name, email, phone, CV (PDF or Word, up to 5 MB) and a consent tick.
  2. The CV goes into private storage. It's a Lovable Cloud storage bucket with no public link, at cvs/<company>/<application-id>.pdf.
  3. An application row is saved. It's linked to the job, so the employer can still see every applicant if an email goes astray.
  4. The Edge Function sends the email. It reads the job's apply_email and sends through Lovable Emails or Resend, from the portal's verified domain. Reply-To is set to the candidate, so HR just hits Reply.
  5. The candidate gets an acknowledgement. A short "we've received your application" email.
  6. Old CVs are cleaned up. A scheduled job deletes CVs after the retention period the employer sets, e.g. 6 months.

Attach the CV, or send a link?

Recommended for SMEs

Attach the file

  • The CV lands in Gmail or Outlook like any normal application
  • Nothing for HR to log in to
  • Keep the upload cap small (5 MB) so the email stays well inside mailbox limits
  • Needs Resend, because its API supports attachments
Option

Send a secure link

  • The email carries a link that expires, e.g. after 7 days
  • The CV never sits in a mailbox, which makes privacy and retention easier
  • An expired link needs a "resend link" flow
  • Works with any email provider

Route A · Recommended

Write the job straight to the database

Claude uses the Lovable query_database tool to insert one row into jobs. The page shows it right away. No code changes and no redeploy.

Route B

Ask the Lovable agent to edit the app

Claude uses send_message to brief Lovable's agent. That's right for layout changes, but each message uses Lovable credits and changes code. It's overkill for a job post.

One-time setup the employer does

  1. Get their own copy of the portal. Remix the template into their own Lovable workspace and turn on Lovable Cloud.
  2. Connect Lovable in Claude. Tap +, then Connectors, Browse connectors, Lovable, Connect, and sign in to Lovable.
  3. Tell Claude which project is theirs. For example: "My careers portal is the Lovable project acme-careers."
  4. Post, edit and close jobs in chat. Try it below.
